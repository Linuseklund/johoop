# Jhoop

Egen webbapp som läser puls och RR-intervall från ett pulsband via Web Bluetooth (standard Heart Rate Service) och räknar ut belastning (0–21), återhämtning (%), HRV och kalorier. All data sparas lokalt i webbläsaren.

Öppna i Bluefy (iPhone) eller Chrome (Android/dator). Slå på Broadcast Heart Rate i bandets app först.
